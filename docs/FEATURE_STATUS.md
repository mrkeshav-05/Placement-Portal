# Feature Status

Use `Persistent`, `Partial`, `Local`, or `Planned`. Update this file in the same pull request that changes a status.

The **Data path** column records which service reaches the database, because moving every path to `FastAPI` is the outstanding work from the 2026-08-20 decision in `docs/DECISIONS.md`.

Every admin list below renders through the shared `DataTable` in `frontend/src/components/common/data-table.tsx`, which supplies search, per-column sorting, multi-select filters, column visibility, pagination, and the loading and empty states. Where a row below names filters or a search, those are that screen's configuration of the shared table rather than a private implementation.
